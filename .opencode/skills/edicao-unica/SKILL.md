# Edicao Unica em Lote

- Leia arquivo 1 vez.
- Planeje mentalmente todas as edicoes.
- Execute todas com Edit tool em sequencia.
- NAO adicione comentarios no codigo.
- NAO explique o que fez.
- Nao pergunte "posso?" — so faca.
- Ao terminar o arquivo, va pro proximo. Zero conversa.
